# 🧠 LITESTATE — BASE CONCEPTUAL Y TÉCNICA (RESUMEN)

## 🎯 PROPÓSITO

Sistema web para **visualizar en tiempo real el estado operativo** de una empresa, enfocado en:

* simplicidad
* rapidez de carga
* claridad visual en monitores (TV / pantallas)

---

## 🧭 ENFOQUE PRINCIPAL

El sistema NO gestiona tareas ni órdenes complejas.

El sistema está orientado a:

> “Capturar y mostrar el estado actual de cada sector en tiempo real, con información mínima clave.”

---

## 🧱 MODELO CONCEPTUAL

### 🔹 Estado actual

* Representa qué está pasando ahora en cada sector
* 1 estado por sector
* visible en dashboards

---

### 🔹 Eventos

* Cada cambio de estado genera un registro histórico
* Permite trazabilidad y métricas futuras

---

## 🏭 ENTIDADES PRINCIPALES

* Empresa
* Usuario
* Sector
* Estado
* Evento
* EstadoActual (optimización)
* Dashboard (monitores)

---

## 👤 ROLES

### Operador

* carga estados
* asignado a un sector

### Supervisor

* visualiza información
* acceso completo

---

## 📺 MONITORES (CLAVE DEL SISTEMA)

No son usuarios tradicionales.

Se implementan como:

> “Dashboards accesibles por URL con token”

Ejemplo:

```
/monitor/{token}
```

---

## 🎯 TIPOS DE DASHBOARD

1. General (todos los sectores)
2. Por sector
3. Administrativo (más detalle)

---

## 👤 USUARIOS Y SECTORES

Un usuario puede estar asignado a uno o varios sectores.

Esto se implementa mediante una relación:

Usuario ↔ Sector (muchos a muchos)

Tabla:

UsuarioSector

* UsuarioId
* SectorId

---

## ⚡ FLUJO DEL OPERARIO (ACTUALIZADO 7/5/2026)

1. Login
2. Selecciona sector (si tiene más de uno)
3. Completa hasta 3 campos
4. Presiona estado
5. El sistema guarda automáticamente

Optimización:

* recordar último sector usado
* permitir cambio rápido de sector

Tiempo objetivo: **2–3 segundos**
---

## 🧩 CAMPOS CONFIGURABLES (DECISIÓN CLAVE)

Cada sector puede definir:

> Hasta 3 campos configurables

Tipos:

* Texto corto
* Número
* Lista (opcional)

Ejemplos:

* Orden
* Lote
* Cantidad
* Máquina
